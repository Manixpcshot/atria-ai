# Atria v0.7.6 — Windows x64

## نصب و اجرا

1. از بخش **Assets** این Release فایل `Atria-Dawn-win64.zip` را دانلود کنید.
2. ZIP را کامل در پوشه‌ای دلخواه استخراج کنید؛ فایل‌های داخلش را جدا نکنید.
3. `Atria.exe` را اجرا کنید. این نسخه پرتابل است و نصب‌کنندهٔ جداگانه ندارد. فایل مستقل `atria.exe` نیز از Assets قابل دریافت است.
4. در اجرای اول به **تنظیمات ← اتصال جدید** بروید، سرویس‌دهنده و مدل را مشخص کنید و کلید API خودتان را وارد کنید. **هیچ کلید APIای داخل برنامه نیست.**

نیازمند Windows 10/11 و WebView2 Runtime است. اگر WebView2 نصب نیست، آن را از [صفحهٔ رسمی مایکروسافت](https://developer.microsoft.com/microsoft-edge/webview2/) نصب کنید.

## تغییرات

- بازطراحی صفحهٔ تنظیمات به‌صورت یک تجربهٔ یکپارچه و واکنش‌گرا، هماهنگ با تم اصلی برنامه؛ تب‌ها، عنوان صفحه و وضعیت اتصال با هم هماهنگ‌اند.
- بازسازی کامل انتخاب‌گر مدل: گروه‌بندی بر اساس اتصال، نمایش مدل/نوع API/اتصال، نشان مدل فعال، جست‌وجو و انتخاب با صفحه‌کلید.
- تعمیر جست‌وجوی فهرست مدل‌های دریافتی از سرور و نمایش روشنِ حالت بدون نتیجه.
- پاسخ‌های طولانی پس از رسیدن به سقف توکن تا سه بار ادامه پیدا می‌کنند؛ مهلت خواندن جریان افزایش یافته و تلاش‌های موقت دوباره انجام می‌شوند.
- رد کردن جریان‌های ناقص و JSON ناقص فراخوانی ابزار، پاک کردن متن ناقص بین retryها، و نمایش خطای روشن به‌جای پایان بی‌توضیح در سقف دورهای ایجنت.

## فایل‌های انتشار

- `atria.exe` — برنامهٔ پرتابل Windows x64.
- `Atria-Dawn-win64.zip` — `Atria.exe` به‌همراه README و LICENSE.
