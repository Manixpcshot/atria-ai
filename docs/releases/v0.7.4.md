# Atria v0.7.4 — Windows x64

## نصب و اجرا

1. از بخش **Assets** همین Release فایل `Atria-Dawn-win64.zip` را دانلود کنید.
2. ZIP را کامل در پوشه‌ای دلخواه Extract کنید؛ فایل‌های داخلش را جدا نکنید.
3. `Atria.exe` (داخل ZIP) را اجرا کنید. این نسخه پرتابل است و نصب‌کنندهٔ جداگانه ندارد. اگر فقط خود برنامه را می‌خواهید، می‌توانید فایل مستقل `atria.exe` را از Assets دانلود و اجرا کنید.
4. در اجرای اول به **تنظیمات ← اتصال جدید** بروید، سرویس‌دهنده و مدل را مشخص کنید و کلید API خودتان را وارد کنید. **هیچ کلید APIای داخل برنامه نیست.**

نیازمند Windows 10/11 و WebView2 Runtime است. اگر WebView2 نصب نیست، آن را از [صفحهٔ رسمی مایکروسافت](https://developer.microsoft.com/microsoft-edge/webview2/) نصب کنید.

## تغییرات

- یکپارچه‌سازی صفحهٔ تنظیمات با چیدمان سازگار و واکنش‌گرای اتصال‌ها؛ همهٔ تب‌ها و پشتیبانی چندسرویس‌دهنده حفظ شده‌اند.
- جست‌وجوی واقعی در منوی مدل و فهرست مدل‌های دریافت‌شده از سرور، همراه با پیامِ نتیجهٔ خالی.
- جلوگیری از ایجاد اتصال ساختگی در نصب تازه، پاک‌سازی پیش‌نویس‌های خالیِ خودکار و جلوگیری از اتصال تکراری با کلیک دوباره.
- مهاجرت تنظیمات قدیمی فقط در صورت وجود مقدار واقعاً پیکربندی‌شده؛ فهرست ذخیره‌شدهٔ خالی، اتصال حذف‌شده را دوباره زنده نمی‌کند.

## فایل‌های انتشار

- `atria.exe` — برنامهٔ پرتابل Windows x64.
- `Atria-Dawn-win64.zip` — `Atria.exe` به‌همراه README و LICENSE.
