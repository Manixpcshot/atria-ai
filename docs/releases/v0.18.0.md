# آتریا v0.18.0

## یک نسخهٔ بزرگ: ۱۷ قابلیت تازه

این نسخه مجموعهٔ کامل «ایده‌ها» است که قرار بود آتریا را به دستیارِ همه‌کارهٔ دسکتاپ تبدیل کند: از درگ‌اند‌دراپ و گویندگی تا زمان‌بندی وظایف، حافظهٔ خودکار، CLI مستقل و مرکز اتصال‌ها (Atria Hub).

## ۱) درگ‌اند‌دراپ فایل و تصویر
فایل یا عکس را **مستقیم روی پنجرهٔ آتریا رها کن** — مثل هر چت‌اپی مدرن. فایل‌های متنی کوچک بلافاصله خوانده و در صف پیوست می‌روند؛ بقیه (باینری/تصویر) از همان کارت آپلود یکپارچهٔ v0.17.0 عبور می‌کنند. همان سقف‌های امن (۴ تصویر، ۶ فایل) در عمل است.

## ۲) برچسب‌های شخصی (`/snippet`)
عبارت‌های تکراری‌ات را یک بار بنویس و با `/` بفریخوان:
- تایپ `/` در جعبهٔ پیام منوی برچسب‌ها را باز می‌کند؛ `/na` همان لحظه فیلتر می‌شود؛ Enter/Tab اعمال، Esc بستن.
- مدیریت کامل در مودال «برچسب‌ها» (افزودن/ویرایش/حذف) — همهٔ چیز در `localStorage`، بدون سرور.
- دکمهٔ «» کنار جعبهٔ پیام برای افزودن سریع.

## ۳) جست‌وجوی داخل چت
دکمهٔ 🔍 در نوار چت: **زیرنویس زندهٔ همهٔ نتیجه‌ها + شمارندهٔ ۱/۳ + قبلی/بعدی**. جست‌وجو در متنِ نمایش‌داده‌شده (فارسی/انگلیسی/RTL) با سقف ۴۰۰ نتیجه و پاک‌سازی کامل نشانه‌ها هنگام بستن.

## ۴) کلیپ‌بورد → جعبهٔ پیام
دکمهٔ 📋 در کنار جعبه: متنِ کلیپ‌بورد ویندوز (CF_UNICODETEXT، سقف ۵۰٬۰۰۰ کاراکتر) را با یک کلیک داخل پیام می‌گذارد.

## ۵) اعلان ویندوز وقتی آتریا در پس‌زمینه است
وقتی پاسخ تمام شد و پنجرهٔ آتریا **فوکوس نداشته باشد** (به برنامهٔ دیگری رفته‌ای):
- **Toast + لرزش وظیفه + بوق نرم** (Taskbar flash + beep) از طریق پنجرهٔ message-only.
- اگر پنجره فوکوس داشته باشد، فقط toast درون‌اپ (سر و صدا نمی‌کند).
- تنظیم «اعلان هنگام پایان اجرا» در Settings قابل خاموش‌کردن است (پیش‌فرض روشن).

## ۶) پیش‌تنظیم‌های اتصال (با یک کلیک)
در تب «اتصال‌ها» یک ردیف چیپ‌های آماده:
- **Ollama** (http://127.0.0.1:11434)، **LM Studio** (http://127.0.0.1:1234)، **OpenRouter** (کلید لازم)، **DeepSeek**، **Mistral**، **Groq** و OpenAI/Anthropic پیش‌فرض.
- یک کلیک = اتصال ساخته، فعال می‌شود و فرم با مقادیر درست باز می‌ماند تا کلیدت را بزنی.

## ۷) پیش‌نمایش diff رنگی برای نوشتنِ مقدماتی (staged)
هر `write_file` در حالت عادی **فقط مقدماتی است**؛ حالا خروجی‌اش یک **diff رنگی** می‌شود:
- خطوط سبز `+`، قرمز `-`، خاکستری context — با سربرگ `--- current / +++ proposed` و سقف ۶۰۰ خط.
- دکمه‌های «اعتماد/رد» همان‌جا: اعمال، رد، یا بازگرداندن نسخهٔ پیشین (باکاپ).

## ۸) Atria Hub: مرکز اتصال‌های MCP + محیطی
حالا سرور MCP **متغیرهای محیطی (`env`)** می‌پذیرد (حداکثر ۱۶ عدد K=V) و یک **هَبِ انتخابی** داخل مودال MCP:
- چیپ‌های آمادهٔ `fetch`، `memory`، `time` و `filesystem` (npx) — یک کلیک می‌افزاید و خودکار تست می‌کند.
- `mcp_test_server` متغیرهای محیطی را هم منتقل می‌کند تا تست واقعی باشد.

## ۹) زمان‌بندی وظایف (⏰)
**وظیفهٔ تکراری یا یک‌باره برای هر ساعتی** — حتی وقتی آتریا بسته است:
- مودال «زمان‌بندی» (دکمهٔ ⏰ نوار کناری): برچسب، متنِ وظیفه، «یک‌باره در …» یا «هر … دقیقه» (۱۵ تا ۱۴۴۰)، سرویس متصل (پیش‌فرض: سرویسِ فعلی که خودت ذخیره می‌کنی).
- اجراگر در بک‌گراند هر ۳۰ ثانیه چک می‌کند؛ وظیفه فقط با **سرویسِ ذخیره‌شده** اجرا می‌شود (کلیدها هرگز در فایل وظایف نیستند).
- نتایج در چتِ جداگانهٔ «⏰ زمان‌بندی‌ها» می‌نشینند؛ اگر در زمان اجرا آتریا نباشد، با باز شدن **پشت‌گزار می‌شود** (catch-up یک‌باره‌ای).
- سقف ۳۲ وظیفهٔ فعال، لاگ JSONL در `~/.atria/scheduled.log`، حذف خودکار یک‌باره‌ها پس از اجرا.

## ۱۰) `run_code`: اجرای کد به‌صورت ایمن
ابزار تازه‌ای که **کد را با تفسیرگر همان زبان اجرا می‌کند** (بدون نوشتن فایل):
- `python`, `node`, `bash`/`sh`, `powershell`، `ruby` — هرکدام اگر روی سیستم باشد.
- در حالت عادی مثل دستور ترمینال: **مقدماتی + تأیید تو**؛ در Full Access: مستقیم.
- خروجی stdout/stderr/کدِ خروجی در کارت ابزار log می‌شود.

## ۱۱) حافظهٔ خودکار + دکمهٔ 🧠
- **پشت دکمهٔ هر پاسخِ هوشمند دو آیکون:** 🔊 (خواندن با صدا) و 🧠 (خلاصه‌کردن نکاتِ همین پیام در حافظهٔ بلندمدت — بدون مدل، با استخراج ساختاریافته).
- **حافظهٔ خودکار** (Settings، پیش‌فرض خاموش): پایان هر اجرا، نکاتِ ماندگارِ گفتگو به‌صورت پس‌زمینه در حافظهٔ بلندمدت می‌نشینند؛ اگر نکته‌ای نباشد، هیچ.

## ۱۲) استخراج متن از PDF/Office
ابزار `extract_text` برای **سندخوانی**:
- **docx / xlsx** (سلول‌ها) با unzip+XML، **PDF** (متن‌های فشرده Flate) با parser داخلی، و txt/md/csv مستقیم.
- محدودهٔ دسترسی دقیقاً تابع scope فعلی است (عادی = ورک‌اسپیس؛ Full Access = هر مسیر) و سقف حجم/تعداد دارد.

## ۱۳) کلید ترکیبی سراسری (Ctrl+Alt+A)
**کجا که باشی، Ctrl+Alt+A** آتریای را جلو می‌آورد (یا اگر باز باشد، فوکوسش می‌کند). از طریق پنجرهٔ message-only ویندوز — بدون دسترسی ادمین.

## ۱۴) چندعاملی (Multi-agent): `multi_search`
ابزار **جست‌وجوی موازی**: ۲ تا ۵ پرسشِ جدا را **همزمان** از چند موتور جست‌وجو می‌پرسد و نتایج را به‌ترتیبِ پرسش‌ها برمی‌گرداند. (عامل‌های مستقل با حافظهٔ مشترک برای نسخه‌های بعدی — این نسخه پایهٔ موازی‌سازی است.)

## ۱۵) Code Work: وضعیت مخزن GitHub
در مودال پروژه، **فیلد `repo`** (فرمت `owner/name` + دکمهٔ «بررسی»):
- از API عمومی GitHub (بدون توکن): نام مخزن، توضیح، ستاره‌ها، issueهای باز، آخرین commit و branch پیش‌فرض — یک خطِ خوانا زیر فیلد.
- حالا «پروژه» واقعاً به **مخزنِ واقعی** وصل می‌شود.

## ۱۶) `atria` CLI — دستیارِ خط‌دستور
کرییت تازهٔ `crates/atria-cli` با باینری **`atria`**:
- `atria "پرسش"` → پاسخ مستقیم در ترمینال؛ `--model`، `--json`، `--tools` (فهرست ابزارها)، `--init` (فایل پیکربندی).
- **کلید فقط از محیط** (`ATRIA_API_KEY`) — هرگز روی دیسک نمی‌نشیند؛ `~/.atria/cli.json` فقط سرویس/مقیاس/بهره‌وری است.
- همان هستهٔ Rust (ابزارها، حافظه، جست‌وجو) — یکپارچه با دسکتاپ.

## ۱۷) صوت: ورودی (میک) + خروجی (گوینده)
- **🎤 در جعبهٔ پیام**: گفتار فارسی/انگلیسی → متن (Web Speech API مرورگر؛ اگر پشتیبانی نبود دکمه خودش می‌خوابد).
- **🔊 روی هر پاسخ**: خواندن با **گویندهٔ سیستمی** (speechSynthesis) — صدا و سرعت قابل تنظیم در Settings؛ تنظیم «خروجی صوتی» پیش‌فرض روشن.

## معماری و امنیتی
- **13 دستور Rust تازه** در `atria-app` (clipboard، notify، repo info، memory extract، files read/stash، و 8 دستور زمان‌بندی) — همهٔ سقف‌دار و log‌شده.
- **زمان‌بسندهٔ Rust** (`scheduler.rs`) در spawn جدا، فایل `~/.atria/scheduled.json` (حداکثر ۳۲)، laگ JSONL، و رویداد `atria:schedule_result` به UI.
- **MCP env**: هر متغیر K=V (≤۱۶، ≤۵۱۲ کاراکتر) — بدون shell، مستقیم به process.
- `extract_text` و `run_code` **بدون Full Access محدود به ورک‌اسپیس**؛ هیچ دسترسی جدیدی به کل سیستم داده نشده — فقط همان scope‌های فعلی.
- **هیچ credential جدیدی روی دیسک نیست**: کلید زمان‌بندی = اشاره به سرویسِ ذخیره‌شده؛ CLI فقط از محیط می‌خواند.
