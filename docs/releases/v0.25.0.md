# v0.25.0 — مدل محلی: دانلود، اجرای درون‌اپ و اتصال خودکار + رفع باگ توقف دانلود

## 🤖 مدل متن محلی واقعاً «کار می‌کند» — نه فقط دانلود می‌شود
- **نصب موتور محلی:** داخل پنجرهٔ «مدل‌ها» بخش جدید «مدل محلی» — با یک کلیک موتور **llama.cpp** (حدود ۲۳MB) دانلود و نصب می‌شود (با نوار پیشرفت)
- **اجرای محلی:** روی هر مدل `.gguf`ِ آمادهٔ دانلود، دکمهٔ **«▶ اجرای محلی»** — مدل روی سخت‌افزار خودتان اجرا می‌شود (بدون ابر، بدون API key، کاملاً آفلاین)
- **اتصال خودکار به چت:** پس از شروع، مدل به‌صورت خودکار به‌عنوان ارائه‌دهندهٔ `conn_local_llama` (OpenAI-compatible) به چت وصل می‌شود — همان چت عادی، فقط با مدل شما
- **تنظیمات:** پورت (پیش‌فرض 8790) و اندازهٔ context (پیش‌فرض 4096) قابل تنظیم است؛ وضعیت زنده (نصب‌شده/در حال اجرا/آماده + مدل بارگذاری‌شده) همیشه نمایش داده می‌شود
- موتور هنگام بستن برنامه به‌صورت تمیز متوقف می‌شود

## 🐞 باگ اصلی «دکمهٔ دانلود کار نمی‌کند» پیدا و رفع شد
- **مشکل:** وقتی دانلود را **متوقف (pause)** می‌کردید، فایل ناقص به‌عنوان «Done» با حجم کامل علامت می‌خورد؛ در **resume** سیستم می‌فهمید فایل «اضطراری موجود» است و آن را **رد می‌کرد** — یعنی مدل خراب/ ناقص، بدون هیچ خطایی، «آماده» نشان داده می‌شد
- **رفع:** توقف حالا وضعیت مستقل `Paused` برمی‌گرداند (نه Done)؛ resume واقعاً از جایی که قطع شده ادامه می‌دهد + تست ریگرسیون

## 🖼 فولدر خروجی عکس‌ها قابل تنظیم شد
