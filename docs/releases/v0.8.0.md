# Atria v0.8.0 — Projects, safer edits, signed updates

## نصب و اجرا (Windows 10/11 x64)

1. از بخش **Assets** همین Release فایل `Atria-Dawn-win64.zip` را دانلود کنید.
2. ZIP را کامل در پوشه‌ای دلخواه استخراج کنید؛ فایل‌ها را جدا نکنید.
3. `Atria.exe` را اجرا کنید. این نسخه پرتابل است؛ نصب‌کنندهٔ جداگانه ندارد. فایل مستقل `atria.exe` نیز موجود است.
4. در اجرای اول از **تنظیمات ← اتصال جدید** ارائه‌دهنده و مدل را مشخص کنید و کلید API خودتان را وارد کنید. هیچ کلید API داخل برنامه نیست.
5. اگر WebView2 Runtime نصب نیست، آن را از [صفحهٔ رسمی مایکروسافت](https://developer.microsoft.com/microsoft-edge/webview2/) نصب کنید.

## تغییرات v0.8.0

- **پروژه‌ها و ادامهٔ کار:** یادداشت‌های ماندگار، فهرست کارها، checkpoint خودکار پس از پاسخ و ادامه در گفتگوی تازه با زمینهٔ پروژه.
- **تغییر فایل با تأیید کاربر:** عامل ابتدا diff را آماده و نمایش می‌دهد؛ تا فشردن «تأیید و اعمال» فایل دست‌نخورده می‌ماند. پیش از اعمال، نسخهٔ قبلی ذخیره می‌شود و دکمهٔ «بازگردانی» دارد. اگر فایل بعد از ساخت پیش‌نمایش تغییر کرده باشد، اعمال رد می‌شود تا تغییر تازه بازنویسی نشود.
- **مدیریت پنجرهٔ متن:** برآورد مصرف توکن، بودجهٔ قابل تنظیم، نگه‌داشتن پیام‌های تازه و فشرده‌سازی extractive تاریخچهٔ قدیمی به زمینهٔ خلاصه‌شده؛ متن کامل گفتگو در برنامه باقی می‌ماند.
- **آزمون اتصال و مدل:** درخواست کوتاه واقعی برای بررسی اتصال، پاسخ مدل و زمان رفت‌وبرگشت. ممکن است هزینهٔ بسیار کمی از ارائه‌دهنده داشته باشد.
- **ذخیرهٔ امن کلیدها:** کلیدها در Windows Credential Manager (مخزن Generic Credentials) برای حساب فعلی ذخیره می‌شوند؛ مشخصات اتصال در localStorage می‌ماند، نه خود کلید. کلیدهای plaintext نسخه‌های پیشین هنگام اجرا به‌صورت خودکار منتقل و از localStorage حذف می‌شوند.
- **انتخاب‌گر مدل:** علاقه‌مندی‌ها و فیلتر «فقط علاقه‌مندی‌ها»؛ برچسب‌های تصویر/ابزار/استدلال از نام مدل و دادهٔ ثبت‌شده استنتاج می‌شوند و ممکن است برای سرویس‌های سفارشی نیاز به بررسی داشته باشند.
- **به‌روزرسانی امضاشده:** برنامه هنگام اجرا Release رسمی را بررسی می‌کند. پیش از نصب، امضای Ed25519 مانیفست و SHA-256 فایل با کلید عمومی تعبیه‌شده اعتبارسنجی می‌شود؛ نصب خودکار فقط با تأیید کاربر انجام می‌شود. اگر پوشهٔ نصب اجازهٔ نوشتن ندهد، فایل را از Release رسمی دستی جایگزین کنید.

## دارایی‌های انتشار و اصالت

- `atria.exe` — برنامهٔ پرتابل Windows x64.
- `Atria-Dawn-win64.zip` — برنامه به‌همراه README و LICENSE.
- `SHA256SUMS.txt` — هش‌های SHA-256 برای فایل‌های برنامه.
- `update-manifest.json` و `update-manifest.sig` — فهرست دارایی‌های Release و امضای Ed25519 آن؛ برنامهٔ به‌روزرسانی این دو را بررسی می‌کند.

### به‌روزرسانی دستی

اگر نصب خودکار به‌دلیل مجوز نوشتن انجام نشد: برنامه را ببندید، `Atria-Dawn-win64.zip` را از Release رسمی دانلود کنید، در پوشهٔ فعلی استخراج و فایل‌های قبلی را جایگزین کنید، سپس `Atria.exe` را دوباره اجرا کنید. فایل‌های دادهٔ کاربر در پوشهٔ دادهٔ برنامه جدا از ZIP نگه‌داری می‌شوند. برای کنترل اختیاری ZIP، در PowerShell اجرا کنید:

```powershell
(Get-FileHash .\Atria-Dawn-win64.zip -Algorithm SHA256).Hash.ToLower()
Get-Content .\SHA256SUMS.txt
```

مقدار SHA-256 چاپ‌شده را با سطر `Atria-Dawn-win64.zip` مقایسه کنید. نصب خودکار نیازمند اتصال اینترنت و اجازهٔ نوشتن در پوشهٔ نصب است. این امضای مانیفست برای اعتبارسنجی به‌روزرسانی است و **گواهی Authenticode ویندوز برای خود EXE نیست**.
