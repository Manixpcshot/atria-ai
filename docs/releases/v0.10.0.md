# آتریا v0.10.0

## قابلیت‌های تازه

- **Full Access اختیاری:** حالت پیش‌فرض خاموش است و فقط پس از انتخاب صریح کاربر و تأیید هشدار روشن می‌شود. وقتی فعال باشد، ابزارهای موجودِ فایل/وب و عملیات allowlist‌شدهٔ GitHub برای هر اقدام prompt جداگانه نمی‌گیرند؛ وضعیت با نشان هشدار در رابط دیده می‌شود و از تنظیمات قابل‌خاموش‌کردن است.
- **نوشتن خودکار فایل با محدودهٔ انتخابی:** می‌توان نوشتن را به ورک‌اسپیس یا مسیرهای نسبی زیر پروفایل کاربر ویندوز محدود کرد. AppData، داده‌های خصوصی آتریا، مسیرهای حساس کلید/اعتبارنامه/پیکربندی، فایل‌های `.env` و symlinkها مسدودند؛ تغییرهای اعمال‌شده نسخهٔ پشتیبان قابل‌بازگردانی دارند.
- **وب و GitHub بدون تأیید موردی در Full Access:** بازکردن URLهای عمومی و عملیات پشتیبانی‌شدهٔ GitHub خودکار انجام می‌شود. جست‌وجو/خواندن عمومی وب همچنان محدودیت‌های شبکه و URL خودش را دارد.
- **خاموش‌کردن حین اجرا:** خاموش‌کردن Full Access در میانهٔ پاسخ، درخواست توقف آن پاسخ را می‌فرستد؛ اقدامی که از قبل شروع شده باشد ممکن است کامل شود.

## محدوده و ایمنی

Full Access دسترسی نامحدود سیستم‌عامل نیست. ابزار shell، دسترسی مدیر، حذف مستقیم، merge، secrets و تغییر تنظیمات GitHub اضافه نشده‌اند. عملیات GitHub به ایجاد issue/comment/pull request و ایجاد/به‌روزرسانی فایل محدود است و همچنان تابع مجوزهای واقعی توکن Fine-grained است. نوشتن محلی یا به‌روزرسانی فایل GitHub می‌تواند محتوای موجود را جایگزین کند. محتوای فایل‌های خوانده‌شده ممکن است برای تحلیل به ارائه‌دهندهٔ مدل فعال فرستاده شود.

در حالت عادی، تأیید جداگانهٔ تغییرهای GitHub و تأییدهای پیش‌فرض دیگر حفظ می‌شوند؛ حالت خودکار محدود قبلی نیز مستقل باقی می‌ماند.
