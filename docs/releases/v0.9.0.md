# آتریا v0.9.0

## قابلیت‌های تازه

- **وب برای همهٔ ارائه‌دهنده‌ها:** جست‌وجوی عمومی و خواندن متن صفحات از ابزارهای مستقل مدل؛ اعتبارسنجی URL، محدودیت میزبان/درگاه و حجم، دنبال‌نکردن تغییرمسیر به شبکهٔ محلی، و بدون اجرای اسکریپت یا دریافت فایل باینری.
- **GitHub:** اتصال توکن تازهٔ Fine-grained از تنظیمات، ذخیره در Windows Credential Manager، و ابزار خواندن/جست‌وجوی مخزن، issue، pull request و فایل.
- **تغییرهای GitHub با تأیید جداگانه:** پیش‌نمایش پیش از هر ایجاد issue/comment/PR یا ایجاد/به‌روزرسانی فایل؛ آپدیت فایل فقط با تطبیق SHA فعلی انجام می‌شود. تأیید هر پیش‌نویس یک‌باره است تا خطای شبکه یا کلیک مجدد همان mutation را دوباره نفرستد. حذف و merge ارائه نمی‌شود.
- **سیاست کنترل رایانه:** انتخاب «پرسش پیش از اقدام» یا «خودکارِ محدود». حالت خودکار فقط می‌تواند URL عمومی را در مرورگر پیش‌فرض باز کند و فایل داخل ورک‌اسپیس را با پشتیبان قابل‌بازگشت تغییر دهد. GitHub همچنان همیشه تأیید می‌خواهد؛ شِل، دسترسی مدیر و کنترل سراسری ماوس/صفحه‌کلید در این نسخه فعال نیست.
- **حریم خصوصی:** توکن GitHub وارد گفتگو یا درخواست مدل نمی‌شود. محتوای خصوصی‌ای که از GitHub می‌خوانید برای تحلیل به مدل فعال ارسال می‌شود.

## تنظیم امن GitHub

توکن قبلیِ افشاشده را استفاده نکنید. اگر هنوز انجام نشده، آن را revoke کنید و در تنظیمات برنامه یک Fine-grained PAT تازه با دسترسی فقط به مخزن‌های لازم بسازید. هیچ توکنی را در گفتگو قرار ندهید.

## نیازمندی‌ها

Windows 10/11 و WebView2 Runtime. انتشار نهایی تنها پس از موفقیت GitHub Actions و بررسی EXE، ZIP، checksum و امضای مانیفست آمادهٔ انتشار است.
