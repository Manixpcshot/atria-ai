# آتریا v0.22.0

## چندسیستم‌عاملی — بسته‌بندی برای ویندوز، لینوکس و مک

در این نسخه آتریا برای سه سیستم‌عامل منتشر می‌شود:
- **ویندوز**: `atria.exe` + `Atria-Dawn-win64.zip` + `atria-cli.exe` (همان مسیر همیشه، از CI)
- **لینوکس**: `Atria_0.22.0_amd64.deb` (برای Ubuntu/Debian) + `Atria_0.22.0_amd64.AppImage` (همه توزیع‌های رایج x86-64)
- **مک**: `Atria-Dawn-macos.dmg` (بیلد universal — روی Apple Silicon و Intel هر دو می‌چرخد)

آپدیت خودکار دسکتاپ فعلاً برای ویندوز است؛ برای لینوکس و مک به‌روزرسانی با دانلود نسخهٔ جدید انجام می‌شود.

CLI هم سه binary دارد: `atria-cli.exe` (ویندوز)، `atria-cli` (مک) و `atria-cli-linux-x86_64` (لینوکس).

## CLI — حالت فارسی / راست‌به‌چپ

`atria-cli` حالا یک حالت **فارسی و راست‌به‌چپ** دارد؛ پیش‌فرض همان انگلیسی است:
- `atria-cli --fa` یا داخل جلسه `/fa` → رابط فارسی/RTL (بیرنا، راهنما، خطاها، thinking bar، خلاصهٔ دورها).
- `/en` (یا `--en`) → بازگشت به انگلیسی.
- انتخاب در `~/.atria/cli.json` ذخیره می‌شود و در اجرای بعدی حفظ است.
- خطوط فارسی با علامت RTL (U+200F) شروع می‌شوند تا در ترمینال درست راست‌به‌چپ نمایش شوند؛ URL و مسیرها LTR می‌مانند.

## اتصال GitHub — پایدارسازی کامل

کلاینت GitHub (خواندن جست‌وجو/مخزن/issues/فایل‌ها + تغییرهای staged):
- **تلاش مجدد با backoff**: خطاهای شبکه (timeout/DNS/قطع اتصال) و 408/429/5xx برای خواندن‌ها تا ۳ بار با فاصلهٔ ۱/۲/۴ ثانیه (یا `Retry-After` سرور) تکرار می‌شوند.
- **تغییرها (mutation) هوشمند**: فقط روی 408/429/rate-limit تکرار می‌شوند — هرگز retry کورکورانه برای ساخت issue/کامنت/فایل تا دو بار اجرا نشود.
- **cache**: هویت حساب ۱۰ دقیقه و خلاصهٔ مخزن ۵ دقیقه در حافظهٔ پروس می‌ماند (کاهش بار API و پاسخ سریع‌تر).
- **پیام خطای قابل‌فهم و عملیاتی**: کلید منقضی → راهنمای تنظیمات؛ سقف rate-limit → زمان باقی‌مانده؛ 403 دسترسی → دقیق بگوید چه اتفاقی افتاده؛ 404 → چک مالک/مخزن و دسترسی توکن.
- ۴ تست تازه برای policy retry و طبقه‌بندی خطاها.

## آماده‌سازی برای تسک‌های طولانی
