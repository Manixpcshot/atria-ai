# v0.26.1 — رفع باگ شفافیت صفحهٔ مدل‌ها + اعتبارسنجی پوشه (hotfix)

## 🐞 صفحهٔ مدل‌ها دیگر نیمه‌شفاف نیست
- **مشکل:** پس‌زمینهٔ صفحهٔ فول‌اسکرین از `var(--bg)` استفاده می‌کرد — متغیری که اصلاً تعریف نشده بود. نتیجه: پس‌زمینهٔ خالی و **کل چت از پشت صفحهٔ مدل‌ها «توهم» نمایش داده می‌شد**
- **رفع:** پس‌زمینهٔ **کدر و یکدست** (`#0a0d1e`) + `z-index: 1000` (بالای همهٔ لایه‌های اپ)
- **حفاظت:** تست جدید در CI: اگر پس‌زمینهٔ صفحهٔ مدل‌ها رنگ کدر نباشد یا z-index آن پایین بیاید، بیلد می‌شکد

## 📁 اعتبارسنجی مسیر پوشه
- در دایالوگ ویندوز می‌شود مستقیم **مسیر یک فایل** را تایپ و تأیید کرد؛ حالا بک‌اند هر مسیری که پوشه نباشد را با پیام روشن رد می‌کند: «مسیر انتخابی یک پوشه نیست…»
- اعمال شد برای **فولدر دانلود مدل‌ها** و **فولدر خروجی عکس‌ها** + تست رگرسیون برای هر دو
