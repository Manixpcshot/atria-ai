# آتریا v0.20.0

## `atria-cli` — دستیار ترمینال (فضای CMD مثل Claude Code)

علاوه بر اپ دسکتاپ، حالا یک **آژنت ترمینالی** هم داری: `atria-cli.exe` — همان هستهٔ آتریا (ابزارها، حافظهٔ بلندمدت، جست‌وجوی وب) که مستقیم در خط فرمان و با **رابط کاملاً انگلیسی** کار می‌کند.

### نحوهٔ کار
- **جلسهٔ تعاملی (REPL):** بدون آرگومان اجراش کن؛ چند‌نوبته است (زمینهٔ گفتگو نگه داشته می‌شود)، پاسخ **استریم** می‌شود، و هر ابزار با یک خطِ فشرده ثبت می‌شود (`⚙ شروع / ✓|✗ پایان`).
- **یک‌نوبته:** `atria-cli "prompt"` یا `echo "text" | atria-cli` — همان مدل قبلی، اما حالا با استریم و UI انگلیسی.
- **دستورهای جلسه (انگلیسی):** `/help` · `/clear` (پاک‌کردن گفتگو؛ حافظهٔ بلندمدت می‌ماند) · `/model [NAME]` · `/provider [NAME] [URL]` · `/key [VALUE]` (کلید فقط در حافظهٔ جلسه) · `/exit`.

- **Ctrl+C** حین تولید = لغو همان دور؛ **Ctrl+D** = خروج.

### انتخاب پرووایدر — فقط OpenAI
همان‌طور که اپ دسکتاپ چندپرووایدر است، ترمینال هم:
- **در شروع:** `atria-cli --provider NAME`
- **داخل جلسه:** `/provider NAME` (یا `/provider NAME URL-ساختگی` برای سرور اختصاصی/پراکسی)

| نام | توضیح |
|---|---|
| `openai` | OpenAI و هر سرویس سازگار با Chat Completions |
| `anthropic` | Claude — Messages API |
| `deepseek` | DeepSeek API (سازگار با OpenAI) |
| `groq` | Groq |
| `openrouter` | OpenRouter — صدها مدل با یک کلید |
| `gemini` | Google Gemini (اتصال سازگار با OpenAI) |
| `ollama` | مدل‌های محلی روی دستگاه — بدون کلید |
| `deepseekweb` | وب نسخهٔ DeepSeek — کلید = userToken نشست مرورگر |

انتخاب پرووایدر `base_url` پیش‌فرض آن را هم تنظیم می‌کند؛ بعدش با `/model` مدل دلخواهت را بگذار.

### امنیتی (همان اصول آتریا)
- کلید API **فقط از `ATRIA_API_KEY`** (یا `/key` در جلسه) — هرگز روی دیسک نوشته نمی‌شود؛ `~/.atria/cli.json` فقط base_url/model/kind است.
- ابزارهای فایل **محدود به `~/.atria/workspace`**؛ جست‌وجوی وب = متادیتا. اجرای شل فقط در اپ دسکتاپ (با همان قواعد Full Access) — ترمینال در `atria-cli` عمداً خاموش است.
- حافظهٔ بلندمدت مشترک با دسکتاپ است (`~/.atria/memory.json`) — آتریای ترمینال چیزهایی را که دسکتاپ یاد گرفته را هم می‌داند.

### نصب (Windows)
از همین release، `atria-cli.exe` را بگیر و کنار بگذاری (یا به PATH اضافه کن). بدون وابستگی — یک فایل کافی است. برای شروع:
```
atria-cli --init        :: میز cli.json می‌سازد؛ base_url/model را ویرایش کن
set ATRIA_API_KEY=...
atria-cli
```

## تغییرات زیرساختی
