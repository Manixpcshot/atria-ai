# آتریا v0.20.0

## `atria-cli` — دستیار ترمینال (فضای CMD مثل Claude Code)

علاوه بر اپ دسکتاپ، حالا یک **آژنت ترمینالی** هم داری: `atria-cli.exe` — همان هستهٔ آتریا (ابزارها، حافظهٔ بلندمدت، جست‌وجوی وب) که مستقیم در خط فرمان و با **رابط کاملاً انگلیسی** کار می‌کند.

```
C:\> set ATRIA_API_KEY=sk-...
C:\> atria-cli --provider anthropic

provider: anthropic  (https://api.anthropic.com)
model: gpt-4o

  ⚙ list_files {"path": "~\\...\\workspace"}
  ✓ list_files a.txt, b.md, notes/
  ⚙ web_search {"query": "..."}
  ✓ web_search 6 results
  …پاسخ استریم‌شده…
  · 3 rounds · 1,204 in / 210 out tokens
❯
```

### نحوهٔ کار
- **جلسهٔ تعاملی (REPL):** بدون آرگومان اجراش کن؛ چند‌نوبته است (زمینهٔ گفتگو نگه داشته می‌شود)، پاسخ **استریم** می‌شود، و هر ابزار با یک خطِ فشرده ثبت می‌شود (`⚙ شروع / ✓|✗ پایان`).
- **یک‌نوبته:** `atria-cli "prompt"` یا `echo "text" | atria-cli` — همان مدل قبلی، اما حالا با استریم و UI انگلیسی.
- **دستورهای جلسه (انگلیسی):** `/help` · `/clear` (پاک‌کردن گفتگو؛ حافظهٔ بلندمدت می‌ماند) · `/model [NAME]` (بدون آرگومان = فهرست مدل‌های پرووایدر) · `/provider [NAME] [URL]` · `/full [on|off]` · `/key [VALUE]` (کلید فقط در حافظهٔ جلسه) · `/exit`.

- **Ctrl+C** حین تولید = لغو همان دور؛ **Ctrl+D** = خروج.

### انتخاب پرووایدر — فقط OpenAI
همان‌طور که اپ دسکتاپ چندپرووایدر است، ترمینال هم:
- **در شروع:** `atria-cli --provider NAME`
- **داخل جلسه:** `/provider NAME` (یا `/provider NAME URL-ساختگی` برای سرور اختصاصی/پراکسی)

| نام | توضیح |
|---|---|
| `openai` | OpenAI و هر سرویس سازگار با Chat Completions |
| `anthropic` | Claude — Messages API |
| `deepseek` | DeepSeek API (سازگار با OpenAI) |
| `groq` | Groq |
| `openrouter` | OpenRouter — صدها مدل با یک کلید |
| `gemini` | Google Gemini (اتصال سازگار با OpenAI) |
| `ollama` | مدل‌های محلی روی دستگاه — بدون کلید |
| `deepseekweb` | وب نسخهٔ DeepSeek — کلید = userToken نشست مرورگر |

انتخاب پرووایدر `base_url` پیش‌فرض آن را هم تنظیم می‌کند؛ بعدش با `/model` مدل دلخواهت را بگذار.

### FULL Mode — ابزارهای کلاد کد (ترمینال + کامپیوتر + فایل)
- **در شروع:** `atria-cli --full` (یا داخل جلسه `/full on`)
- **چه چیزها روشن می‌شود:**
  - **ترمینال:** `run_command` (cmd/sh) و `run_code` (**PowerShell**، Python، Node) — دقیقاً مثل کلاد کد، روی همان پوشه‌ای که از آن اجرا کرده‌ای
  - **کنترل کامپیوتر:** `system_info` (اسنپشات فقط‌خواندنی) و `open_windows_settings` (صفحات ثابت Settings)
  - **فایل‌ها:** خواندن/نوشتن در **پوشهٔ جاری** (CWD)، نه فقط workspace
- **قواعد امنیتی آتریا حفظ می‌شود:** هر دستور با `⚙` و نتیجه با `✓/✗` **در همان چت لاگ می‌شود** (دستور کامل + کد خروجی + تهِ خروجی)؛ **هیچ ارتقای admin نداریم**؛ محدودیت ۱۲۰ ثانیه و خروجی ۱۶KB؛ با `/full off` هر لحظه برمی‌گردی به حالت عادی.

```
❯ rename all jpgs to lower case and list the top 10 largest files
  ⚙ $ dir /a /s
  ✓ run_command exit 0 · C:\proj\img (12,540 files)
  ⚙ powershell: Get-ChildItem -Recurse -Filter *.jpg | ...
  ✓ run_code exit 0 · renamed 348 files
  …پاسخ استریم‌شده…
  · 3 rounds · 18.4s · 2,410 in / 380 out tokens
```

### نوار thinking + متن رنگی
- مثل کلاد کد: وقتی مدل در حال فکر کردن است (قبل از اولین حرف)، یک خط **`✻ thinking … N.Ns`** بنفش تیک می‌زند و با اولین خروجی پاک می‌شود.
- رابط **رنگی** است (ANSI؛ روی کنسول ویندوز VT فعال می‌شود): prompt `❯` بنفش، `⚙` خاکستری، `✓` سبز، `✗` قرمز، warning FULL زرد. با متغیر `NO_COLOR` یا خروجی غیر-TTY رنگ‌ها خاموش می‌شوند.
- خط پایانی هر دور: تعداد rounds، **زمان** و توکن‌ها.

### آپدیت خودکار
- `atria-cli --update` → آخرین نسخه از GitHub را می‌گیرد، **SHA-256 را با SHA256SUMS.txt ریلیز چک می‌کند** و سپس `atria-cli.exe` را جایگزین می‌کند (روی ویندوز با یک اسکریپت کوچک در پس‌زمینه، چون exe در حال اجرا قابل جایگزینی نیست).
- در شروع هر جلسه (تا ۶ ساعت یک‌بار) اگر نسخهٔ تازه‌تری در ریلیز باشد، یک خط کوتاه: `↑ a newer atria-cli is available — run atria-cli --update`.

### امنیتی (همان اصول آتریا)
- کلید API **فقط از `ATRIA_API_KEY`** (یا `/key` در جلسه) — هرگز روی دیسک نوشته نمی‌شود؛ `~/.atria/cli.json` فقط base_url/model/kind است.
- ابزارهای فایل **محدود به `~/.atria/workspace`**؛ جست‌وجوی وب = متادیتا. اجرای شل فقط در اپ دسکتاپ (با همان قواعد Full Access) — ترمینال در `atria-cli` عمداً خاموش است.
- حافظهٔ بلندمدت مشترک با دسکتاپ است (`~/.atria/memory.json`) — آتریای ترمینال چیزهایی را که دسکتاپ یاد گرفته را هم می‌داند.

### نصب (Windows)
از همین release، `atria-cli.exe` را بگیر و کنار بگذاری (یا به PATH اضافه کن). بدون وابستگی — یک فایل کافی است. برای شروع:
```
atria-cli --init        :: میز cli.json می‌سازد؛ base_url/model را ویرایش کن
set ATRIA_API_KEY=...
atria-cli
```
