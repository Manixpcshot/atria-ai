# آتریا v0.11.0

## اصلاح‌ها و بهبودها

- **رفع بسته‌شدن احتمالی هنگام جست‌وجو:** برش نتیجهٔ HTML اکنون مرز UTF-8 را رعایت می‌کند؛ یک کاراکتر چندبایتی دیگر نمی‌تواند باعث panic هنگام کوتاه‌سازی نتیجه شود.
- **کلید سریع Full Access در نوار گفتگو:** وضعیت خاموش/روشن همیشه دیده می‌شود. خاموش پیش‌فرض باقی می‌ماند؛ روشن‌کردن نیازمند تأیید صریح یک‌باره است و خاموش‌کردن از همان کلید، حتی هنگام تولید پاسخ، در دسترس است.
- **نمایش دیداری روشن‌تر:** حالت خاموش با تأکید ملایم و حالت فعال با هشدار قرمز مشخص می‌شود؛ چیدمان برای پنجره‌های باریک و پیمایش صفحه‌کلید هم بهینه شده است.

## محدوده و ایمنی

Full Access دسترسی نامحدود سیستم‌عامل نیست و هرگز خودش فعال نمی‌شود. پس از انتخاب صریح کاربر، فقط ابزارهای موجود و مجاز Atria می‌توانند بدون تأیید جداگانه اجرا شوند؛ محدودیت‌های فایل، مسیرهای محافظت‌شده و مجوزهای خود توکن GitHub همچنان برقرارند. خاموش‌کردن، توقف پاسخ جاری را درخواست می‌کند؛ اقدامی که از قبل شروع شده باشد ممکن است کامل شود.

Full Access فقط ابزارهای agent موجود در Atria را پوشش می‌دهد: فایل، وب عمومی و عملیات allowlist‌شدهٔ GitHub. اتصال‌های ارائه‌دهنده از صفحهٔ تنظیمات برنامه مدیریت می‌شوند؛ کلیدها در Windows Credential Manager می‌مانند و به مدل فرستاده نمی‌شوند. این نسخه حساب‌های Windows یا مرورگر، گذرواژه‌ها یا نشست‌های مرورگر را کنترل یا افشا نمی‌کند. عملیات GitHub فقط با مجوزهای واقعی توکن انجام می‌شوند.

حالت تأیید پیش‌فرض و حالت خودکار محدود مستقل و بدون تغییر باقی می‌مانند. ابزار shell، دسترسی مدیر، حذف مستقیم، merge، secrets یا تنظیمات GitHub اضافه نشده‌اند.
